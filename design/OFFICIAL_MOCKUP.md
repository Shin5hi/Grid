# Grid — Approved Mockup

Visual reference for the app. The implementation follows the approved images
(dashboard "Hola, Shin5hi", "The Tree" panel, violet G logo, blue Orion bubble).

Approved references, as provided on 2026-10-12:
- Dashboard: greeting, "Resumen inteligente" tiles, "Acceso rápido" rows, 5-item bottom bar.
- The Tree: nested folders with count badges and tree connectors.
- Logo: violet "G" with grid detail on a light rounded square.
- Brand poster: "Grid by Shin5hi", slogan "Crea, Organiza, Avanza.", robot mascot.

Notes on what is not implemented yet:
- The "Resumen inteligente" tiles (Proyectos, Tareas, Herramientas, Notas) and the
  Proyectos/Notas sections need product content that the bot maker does not have.
- The robot mascot is a 3D render and is not part of the app yet.
